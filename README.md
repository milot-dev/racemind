# RaceMind AI

RaceMind AI is a full-stack GenAI and ML-powered MotoGP intelligence platform.

It uses real MotoGP race result data to provide:

- MotoGP data dashboard
- Rider comparison
- RAG racing assistant
- AI commentary generator
- ML performance predictor

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS
- Recharts

### Backend
- FastAPI
- Python
- pandas
- scikit-learn
- OpenAI API optional
- local fallback for GenAI features

### Data
- Kaggle MotoGP Race Results 2022–2025

## Main Goal

Build a portfolio-ready AI Engineering project that demonstrates:

- Data preprocessing
- Backend API development
- Frontend integration
- Retrieval-Augmented Generation
- Prompt engineering
- Machine learning model training
- Model serving
