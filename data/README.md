# Data

This folder contains the dataset files used by **RaceMind AI**.

RaceMind AI uses real MotoGP race result data to power the analytics dashboard, rider comparison page, RAG assistant context, and machine learning performance predictor.

---

## Dataset Source

This project uses the Kaggle dataset:

```txt
MotoGP Race Results (2022–2025)
Dataset slug: sammee/motogp-race-results-2022
```

Dataset link:

```txt
https://www.kaggle.com/datasets/sammee/motogp-race-results-2022
```

The dataset includes race, sprint, and qualifying results from MotoGP-related classes.

For this MVP, the project focuses mainly on **MotoGP race and sprint result analysis**.

```bash

```

The processed file is used directly by the backend and machine learning pipeline.

## Clean Dataset Schema

The processed CSV uses this standardized schema:

```txt
year
series
event_name
session_type
circuit
rider
team
grid_position
finish_position
points
status
number
time_gap
```

Column meaning:

| Column | Description |
|---|---|
| `year` | Race season year |
| `series` | Racing class or category, mainly MotoGP for this MVP |
| `event_name` | Event or Grand Prix identifier |
| `session_type` | Race or Sprint |
| `circuit` | Circuit or event track identifier |
| `rider` | Rider name |
| `team` | Rider team name |
| `grid_position` | Starting grid position, currently empty in the MVP dataset |
| `finish_position` | Final classified position |
| `points` | Championship points earned |
| `status` | Race result status, such as finished, DNF, DNS, RET, DSQ, or NC |
| `number` | Rider number, if available |
| `time_gap` | Time gap or race result gap, if available |

---

## Current Known Limitation

`grid_position` is currently empty because the race result file does not include starting grid position.

A future improvement is to join `Race.csv` with `Qualifying.csv` using:

```txt
year + event + class + rider
```

This would allow RaceMind AI to include starting grid position in:

- rider comparison
- dashboard analysis
- machine learning features
- performance prediction explanations

## How To Regenerate The Processed Dataset

From the project root:

```bash
cd D:\racemind_ai
python scripts/prepare_dataset.py
```

Expected output:

```txt
data/processed/race_results_clean.csv
```

After regenerating the dataset, you can inspect it with:

```python
import pandas as pd

df = pd.read_csv("data/processed/race_results_clean.csv")
print(df.head())
print(df.columns)
print(df.shape)
print(df["year"].value_counts().sort_index())
print(df["session_type"].value_counts(dropna=False))
```
