# RaceMind AI Data

This folder contains the dataset files used by RaceMind AI.

RaceMind AI uses real MotoGP race result data to power:

- dashboard analytics
- rider comparison
- rider profile pages
- race detail pages
- RAG assistant context
- machine learning training
- ML prediction endpoint

---

## Dataset Source

This project uses the Kaggle dataset:

```txt
MotoGP Race Results (2022–2025)
Dataset slug: sammee/motogp-race-results-2022
```

Dataset link:

```txt
https://www.kaggle.com/datasets/sammee/motogp-race-results-2022
```

The dataset includes race, sprint, and qualifying results from MotoGP-related classes.

For this project, the focus is mainly on MotoGP race and sprint result analysis.

## Processed Data

The main processed dataset is:

```txt

```

This file is generated by running:

```bash
python scripts/prepare_dataset.py
```

The processed file is used directly by the backend analytics services and the machine learning pipeline.

## Clean Dataset Schema

The processed CSV uses this standardized schema:

```txt
year
series
event_name
session_type
circuit
rider
team
grid_position
finish_position
points
status
number
time_gap
```

Column meaning:

| Column | Description |
|---|---|
| `year` | Race season year |
| `series` | Racing class or category, mainly MotoGP for this project |
| `event_name` | Event or Grand Prix identifier |
| `session_type` | Race or Sprint |
| `circuit` | Circuit or event track identifier |
| `rider` | Rider name |
| `team` | Rider team name |
| `grid_position` | Starting grid position joined from qualifying data where available |
| `finish_position` | Final classified position |
| `points` | Championship points earned |
| `status` | Race result status, such as finished, DNF, DNS, RET, DSQ, or NC |
| `number` | Rider number, if available |
| `time_gap` | Time gap or race result gap, if available |

---

## Grid Position

`grid_position` is populated by joining `Race.csv` with `Qualifying.csv` using normalized keys:

```txt
year + series + event_name + rider
```

Not every row is guaranteed to have a grid position because names and event identifiers may differ between raw files.

Missing grid positions are handled safely in the ML pipeline by using a fallback value.

## How To Regenerate The Processed Dataset

From the project root:

```bash
cd D:\racemind_ai
python scripts/prepare_dataset.py
```

Expected output:

```txt
data/processed/race_results_clean.csv
```

After regenerating the dataset, inspect it with:

```python
import pandas as pd

df = pd.read_csv("data/processed/race_results_clean.csv")
print(df.head())
print(df.columns)
print(df.shape)
print(df["year"].value_counts().sort_index())
print(df["session_type"].value_counts(dropna=False))
print(df["grid_position"].notna().sum())
```
